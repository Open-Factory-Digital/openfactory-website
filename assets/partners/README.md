# Partner assets

- `altiva.svg`: official logo retrieved from https://altiva.ai/altiva_logo_vetorizada.svg on 2026-09-27. Retained as supplied.
- `world-map.svg`: equirectangular land outlines generated from Natural Earth's public-domain 1:110m land dataset: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson.
- CastelloSoft's wordmark is rendered in HTML using its existing typography, weight and divider color.

Country markers are indicative locations in Brazil and Portugal, not office addresses. Partner names, countries and official status were provided by the site owner. Each partner is an independent business, and their services are optional.
